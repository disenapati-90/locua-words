Cybersecurity vocabulary

Words you meet in a “Cybersecurity” story, each with a clear meaning and an example sentence. In the Locua app these are read in story order so the context helps you remember them.

breach easy

an incident where security measures are bypassed and data is exposed.

“The company discovered the breach nearly three weeks after it happened.”

Synonyms: security failure, intrusion   Opposites: protection, containment

encrypt easy

to convert information into code to prevent unauthorized access.

“All customer data was encrypted before it ever left the server.”

Synonyms: encode, scramble   Opposites: decrypt, expose

phishing medium

a fraudulent attempt to obtain sensitive information by disguising as trustworthy.

“The phishing email looked convincing enough to fool even the IT manager.”

Synonyms: scam email, deceptive request   Opposites:

malicious easy

intended to cause harm.

“Analysts traced the outage to malicious code hidden in a routine update.”

Synonyms: harmful, hostile   Opposites: benign, harmless

vulnerability medium

a weakness that can be exploited by an attacker.

“The patch closed a vulnerability that had existed for over a year.”

Synonyms: weakness, security gap   Opposites: safeguard, protection

obfurcation hard

the deliberate act of making code difficult to understand or analyze.

“The malware used heavy code obfurcation to avoid detection by antivirus tools.”

Synonyms: code disguising, concealment technique   Opposites: clarity, transparency

exfiltration hard

the unauthorized transfer of data out of a system.

“Investigators found evidence of data exfiltration over several months.”

Synonyms: data theft, unauthorized extraction   Opposites: data protection, containment

firewall easy

a system designed to prevent unauthorized network access.

“The outdated firewall failed to catch the intrusion in time.”

Synonyms: network barrier, security filter   Opposites:

redundancy medium

duplication of critical components to increase reliability.

“Built-in redundancy meant the system stayed online despite the attack.”

Synonyms: backup systems, duplication   Opposites: single point of failure, fragility

authentication medium

the process of verifying the identity of a user or system.

“Two-factor authentication likely prevented a far worse outcome.”

Synonyms: identity verification, credential check   Opposites:
